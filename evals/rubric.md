# 기획서 점검 기준

제출 전 각 항목을 pass / warn / fail로 판정한다. fail이 하나라도 있으면 제출하지 않는다.

## 공식 심사 관점

| ID | 항목 | pass 조건 |
|---|---|---|
| E-01 | 참신성 | 하나증권V와 주요 증권사 앱에 같은 기능이 없음을 직접 확인했고, 확인 날짜가 `06_증빙/`에 있다 |
| E-02 | 실현 가능성 | 필요한 데이터, 시스템, 규제 경로가 각각 한 문장 이상으로 적혀 있다 |

## 문제 정의

| ID | 항목 | pass 조건 |
|---|---|---|
| E-03 | 대상 손님 | 한 문장으로 특정된다 (연령, 상황) |
| E-04 | 문제의 순간 | 손님 여정에서 언제 일어나는지 한 장면으로 그려진다 |
| E-05 | 근거 수치 | 원문 확인을 거친 수치가 2개 이상 있다 |
| E-06 | 회사가 잃는 것 | 하나증권의 손실이 구체적으로 적혀 있다 |

## 형식과 규정

| ID | 항목 | pass 조건 |
|---|---|---|
| E-07 | 분량 | A4 3쪽 내외, 가이드의 쪽별 구성을 따른다 |
| E-08 | 서비스 흐름 | 손님이 겪는 단계가 순서대로 설명된다 |
| E-09 | AI 활용 표시 | 도구와 범위가 `06_증빙/AI_활용_기록.md`와 일치한다 |
| E-10 | 응모 제한 | `rules/compliance-rules.md`의 C-01~C-03을 충족한다 |
