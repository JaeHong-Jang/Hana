## 문제 한 줄

오래전에 주식정보 서비스에 가입하고 잊은 손님이, 주문할 때마다 수수료에 얹힌 서비스 값을 모르고 내 왔다. 2027년 1분기까지 회사는 이 사실을 손님에게 알려야 한다.

## 당국이 이미 정한 것과 그 위에 더할 것

금감원(2026-11-11)이 정한 최소 요건을 그대로 옮기면 새로움이 없다. 아이디어는 오른쪽 칸에서 나와야 한다.

| 금감원이 정한 최소 요건 | 그것만으로 남는 빈틈 (조사자 판단) |
|---|---|
| 가입 전: 가입 전후 이용료 총액을 예시로 비교 안내 | 예시 금액이지 내 거래 금액이 아니다 |
| 가입 후 정기: 푸시·문자로 이용 사실과 수수료율 비교 안내 | 요율(%)만 봐서는 내가 낸 돈이 얼마인지 모른다 |
| 수시: 수수료 확인 화면에 이용료 부과체계 설명 추가 | 낸 돈은 보여도 "그만큼 썼는지"는 안 보인다 |
| 기존 가입자: 가입 사실과 해지 URL 일괄 안내 | 선택지가 유지 아니면 해지 둘뿐이다. 한 번 알리고 끝난다 |
| 무료체험: 끝나면 원칙적으로 종료, 동의한 사람만 유료 전환 | 유료로 쓰다가 안 보게 된 손님은 대상이 아니다 |

## 아이디어 선택지

| | 선택지 | 손님이 겪는 변화 | 강점 | 약점 |
|---|---|---|---|---|
| A | 낸 돈과 쓴 만큼을 나란히 | "이번 달 이 서비스 값 9,000원, 열어 본 날 0일"을 한 화면에서 본다 | 당국 요건에 없는 것(쓴 만큼). 손님이 스스로 판단 | 화면 하나라 "보여 주기"에 그칠 수 있음 |
| B | 주문 순간에 나눠 보여 주기 | 주문 확인 창에 "매매수수료 1,416원 + 정보서비스 9,000원"이 따로 찍힌다 | 돈이 나가는 바로 그 순간 | 당국의 "구분 표시" 요구와 가까워 새로움이 약함 |
| C | 안 보면 멈춘다 | 일정 기간 서비스를 안 열면 알림이 오고, 답이 없으면 서비스와 얹힌 수수료가 함께 쉰다. 다시 켜기는 한 번에 | 규칙 하나로 설명됨. 당국의 무료체험 원칙(동의한 사람만 유료)을 기존 가입자에게 넓힌 것 | 회사 수입이 줄어든다는 반론이 가장 셈 |
| D | 요금 방식 바꾸기(상한, 정액) | 많이 거래해도 서비스 값이 일정 금액을 넘지 않는다 | 많이 거래하는 손님의 부담이 큼(월 5,000만 원 거래 시 금감원 예시 42,500원 차이) | 가격 정책이라 학생 기획서가 다루기 어려움 |

**권장 조합(조사자 판단): A를 화면으로, C를 규칙으로.** 3쪽에는 화면 흐름 하나와 규칙 하나가 들어간다. B는 화면 흐름 속 한 장면으로만 쓰고, D는 뺀다.

## 화면 흐름 (권장 조합 기준)

1. **알림**: 체결 직후 알림에 "이 거래에서 서비스 값 얼마가 함께 나갔다"는 한 줄을 붙인다(주 자리). 회사가 어차피 보내야 하는 정기 안내 문자·푸시도 해지 주소 대신 아래 화면으로 연결한다(보조 자리).
2. **내 서비스 영수증 화면**: 가입한 서비스별로 ① 가입한 날 ② 최근 기간에 이 서비스 값으로 낸 돈(매매수수료와 따로) ③ 열어 본 날 수.
3. **세 가지 중 고르기**: 계속 쓰기 / 쉬기 / 해지. 쉬기를 고르면 서비스와 얹힌 수수료가 함께 멈추고, 다시 켜기 단추가 남는다.
4. **그 뒤의 규칙**: 일정 기간 열지 않으면 먼저 알리고, 답이 없으면 쉬기로 넘긴다. 손님이 "묻지 말고 계속"을 골라 두면 넘기지 않는다.

정할 것(응모자 몫): 기간을 며칠로 할지, "열어 봄"을 무엇으로 셀지, 쉬는 동안 다시 켜면 언제부터 수수료가 붙는지(현재 안내는 "신청 익일부터").

## 회사에 좋은 이유 (기획서 3쪽 재료)

- 2027년 1분기 이행 점검에 대비된다. 최소 요건을 넘으므로 점검에서 앞선다(추론).
- 통보를 받은 손님이 "속았다"로 끝나지 않고 "내가 골랐다"로 끝난다(추론).
- 실제로 쓰는 손님은 남고, 어느 서비스가 쓰이는지 회사가 알게 된다(추론).
- 새 시스템이 아니다. 가입 정보, 수수료 계산, 화면 접속 기록은 회사가 이미 갖고 있을 자료다(추론, 확인 못 함).
