# 07 설문과 후기 수집 (응모자가 직접 한다)

- 목적: "정말 이 결정에서 막히는 사람이 있나"에 답할 근거. 심사 점검에서 가장 약한 곳이다.
- 대상: 퇴사나 이직을 해 본 20대 후반~30대, 20명 안팎. 표본이 작으므로 통계로 쓰지 않고 "응모자가 직접 물은 결과(○명)"로만 적는다.
- 아래 문항은 AI가 만든 초안이다. 응모자가 고쳐서 쓴다. 답을 한쪽으로 이끄는 문항은 넣지 않았다.

## 문항 (3분 안에 끝나게)

1. 나이대와, 퇴사·이직을 몇 번 해 봤나요?
2. 가장 최근 퇴사 때 근속 기간은 얼마였나요? (1년 미만 / 1~3년 / 3~5년 / 5년 이상)
3. 퇴직금을 어떻게 받았나요? (IRP 계좌로 / 통장으로 바로 / 퇴직금이 없었다 / 기억나지 않는다)
4. IRP로 받았다면, 그 계좌는 언제 만들었나요? (전부터 있던 계좌 / 퇴사하면서 급히 / 회사가 정해 준 곳에서)
5. 어느 금융사에서 열지는 어떻게 정했나요? (주거래라서 / 회사 안내 / 검색 / 그냥 아무 데나 / 기타)
6. 받은 퇴직금은 지금 어떻게 됐나요? (그대로 두었다 / 전부 해지했다 / 운용 중이다 / 모르겠다)
7. 해지했다면 까닭은 무엇이었나요? (돈이 필요해서 / 금액이 작아서 / 둬야 하는 줄 몰라서 / 관리가 귀찮아서 / 기타)
8. 해지할 때 필요한 금액은 전체의 어느 정도였나요? (전부 / 절반쯤 / 일부만 / 딱히 필요 없었다)
9. 아래 가운데 그때 알고 있던 것을 모두 골라 주세요. (IRP는 일부만 꺼낼 수 없다 / 세액공제용으로 넣던 계좌에 퇴직금을 같이 받으면 해지할 때 세금이 더 붙는다 / 통장으로 받아도 60일 안에 IRP에 넣으면 세금을 돌려받는다 / 아는 것이 없었다)
10. 그 과정에서 막히거나 나중에 아쉬웠던 것이 있으면 적어 주세요. (자유 기술)

## 읽는 법

- 6·7·8번: "일부만 필요했는데 전부 해지"가 몇 명인지가 문제 한 문장을 받친다.
- 9번: 아는 것이 없었다는 답이 많으면 "몰라서 정한다"의 근거가 된다.
- 10번: 그대로 인용할 수 있는 문장을 찾는다. 인용하려면 응답자에게 허락을 받는다.
- "막힌 것이 없었다"가 대부분이면 `docs/04_irp_plan.md`의 멈춤 기준에 걸린다. 결과를 숨기지 않는다.

## 후기

검색어: "첫 퇴사 퇴직금 IRP", "IRP 해지 후기", "퇴직금 IRP 같이 넣었다가", "IRP 전액 해지". 찾은 글은 주소, 날짜, 인용 문장을 `06_증빙/`에 적는다.
