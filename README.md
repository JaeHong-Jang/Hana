# 하나증권 청년 금융아이디어 공모전 워크스페이스

「제1회 하나증권 청년 금융아이디어 공모전」 예선 기획서(A4 3쪽)와 본선 발표를 준비하는 작업 공간이다. 폴더명은 "하나은행 공모전"이지만 주최는 하나증권이다.

- 접수 마감: **2026-11-30(월) 17:00**
- 참가 단위: 개인 (1인 1아이디어, 주제 1개)
- 현재 권고안(3차): 후보 마 "지점 개설 계좌 손님이 앱 수수료 차이를 처음 아는 순간" (주제 02). 차선은 좁힌 후보 가(로그인 못 하는 손님의 복구 고리), 3순위는 고친 후보 나(주제 03). 응모자 확정 전이며 앱 직접 확인 결과에 따라 바뀐다

## 폴더 구조

```text
.
├── 00_제출/        # 최종 제출본, 첨부, 접수번호
├── 01_전략/        # 주제 선택과 문제 정의 후보 비교
├── 02_제품/        # 서비스 아이디어, 손님 여정, 화면 목업
├── 03_에이전트/    # 조사·점검용 프롬프트와 스킬
├── 04_아키텍처/    # 서비스 흐름, 데이터·시스템·규제 경로
├── 05_리서치/      # 날짜가 붙은 리서치 보고서
├── 06_증빙/        # 원문 확인, 앱 캡처, 인터뷰, 문의 답변, AI 활용 기록
├── 07_원천/        # 요강 원문, 기사·보고서 원본
├── 08_본선/        # PPT 10장, 발표 준비
├── _체계/          # 작업 체계 메모
├── data/
│   ├── raw/        # 내려받은 통계 원자료
│   └── processed/  # 기획서에 쓸 수 있게 정리한 수치 표
├── docs/           # 요강 분석, 출처 기록, CPS
├── evals/          # 기획서 점검 기준
├── rules/          # 규정 준수 규칙
├── research_notes/ # 딥리서치 갈래별 원본 노트
├── reports/        # 딥리서치 종합 보고서 원본
└── artifacts/ experiments/ notebooks/ prompts/ scripts/ src/ static/ tests/
                    # 참고 하네스와 같은 뼈대. 구현물이 심사 대상이 아니라 비워 둠
```

## 작업 순서

`요강 → 기업 문제 진단 → CPS → 해결안 → 서비스 흐름 → 근거 검증 → 기획서 3쪽 → 본선 PT`
