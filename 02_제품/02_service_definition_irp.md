## 한 줄로

퇴직금을 받기 전과 깨기 전에 되돌리기 어려운 결정이 다섯 개 있다. 손님의 상황을 듣고 해당하는 결정만 골라, 그 사람의 금액으로 선택지를 나란히 보여 주고, 손님이 고른 대로 준비와 확인을 이어 간다.

## 문제 한 문장 후보 (응모자가 골라 직접 다시 쓴다)

| # | 후보 | 강점 | 약점 |
|---|---|---|---|
| 1 | 100만 원이 필요한데 1,500만 원을 전부 깨야 한다는 것을 깨는 날에야 안다 | 구조가 한눈에 보인다. 세금 반박을 피한다 | "깨는 날에야 안다"를 받칠 통계가 없다. 후기·설문이 필요하다 |
| 2 | 퇴직금을 어느 계좌로 받느냐는 입금 전에만 고를 수 있는데, 그 선택이 무엇을 가르는지 알려 주는 곳이 없다 | 되돌릴 수 없는 한 번의 선택이라 "왜 지금인가"가 선다 | 하나증권에서 퇴직금 계좌가 이미 따로 관리되면 무너진다(고객센터 질문 1번) |
| 3 | IRP를 해지하는 사람의 57.6%가 20~30대인데, 이들에게 맞춘 안내는 은퇴자용 연금 수령 설계뿐이다 | 원문 통계로 시작한다 | "은퇴자용뿐이다"는 앱을 열어 보지 않고는 쓸 수 없다 |

## 누구를 위한 것인가

| 손님 | 상황 | 이 서비스에서 얻는 것 |
|---|---|---|
| 퇴사가 정해진 손님 | 회사가 IRP 계좌를 알려 달라고 한다. 다른 금융사에 세액공제용으로 넣던 IRP가 있다 | 그 계좌로 받을 때와 하나증권에 새로 열어 따로 받을 때 달라지는 것을 입금 전에 본다 |
| 퇴직금이 들어온 손님 | 생활비나 전세 잔금으로 일부가 필요하다 | 일부만 꺼낼 수 없다는 것과, 필요한 금액 대 깨야 하는 금액을 깨기 전에 본다 |
| 이미 현금으로 받은 손님 | 퇴직소득세를 떼고 통장으로 받았다 | 60일 안에 넣으면 돌려받는 세금과 남은 날을 본다 |

대상이 아닌 손님: 근속 1년 미만(퇴직급여 없음), 퇴직급여 300만 원 이하(IRP를 거치지 않음), 만 55세 이상 수령자(기존 연금 수령 설계의 영역).

## 다루는 범위

- 다룬다: 수령 계좌 선택, 입금 전 점검, 회사에 낼 것 준비, 입금 확인, 깨기 전 비교, 현금 수령 뒤 60일, 인출 사유 확인, 연금 상담 직원 인계.
- 다루지 않는다: 입금 뒤 무엇을 살지(기존 'AI 연금프로'의 영역), "유지하세요"라는 권유, 대출 상품 연결, 전 직장이나 타 금융사에 대한 신청 대리, 세무 상담.

## 다섯 결정 지점과 기능

| # | 결정 지점 | 손님이 보는 것 | 뒤에서 일어나는 일 | 화면 |
|---|---|---|---|---|
| 1 | 어느 금융사의 어느 계좌로 받을지 | 세액공제용으로 쓰던 기존 IRP로 받기 / 그 IRP가 없는 금융사에 새로 열어 따로 받기의 결과를 나란히 | 손님이 켠 마이데이터로 기존 IRP를 읽고, 꺼낼 계획이 있는지 되묻는다. IRP는 금융사마다 한 계좌라는 사실을 알린다 | 받을 계좌 |
| 2 | 일부만 필요할 때 | 필요한 금액, 깨야 하는 금액, 해지 시 떼는 금액 | 필요한 금액과 시점을 되묻고, 해지 시 원천징수 예정액을 자사 기록에서 읽는다 | 꺼내기 전 |
| 3 | 현금으로 받은 뒤 60일 | 남은 날, 넣으면 돌려받는 세금, 낼 서류 | 지급일을 묻고 기한을 셈한다. 과세이연계좌신고서 초안을 만든다 | 일정 |
| 4 | 기존 계좌의 자동 운용지시 | "입금되면 이 비율대로 한꺼번에 들어갑니다" | 자사 계좌의 계속성 운용지시와 디폴트옵션 설정을 읽는다 | 받을 계좌 |
| 5 | 인출 사유와 세금 혜택의 차이 | 내 사유가 "꺼낼 수 있는가"와 "세금이 낮은가" 각각 | 사유를 되묻고 두 법령의 사유 표에 대조한다 | 꺼내기 전 |

다섯 지점은 낱개로는 분기형 화면으로도 만들 수 있다(검증 보고서의 정직한 결론). 에이전트 몫은 상황 설명을 듣고 해당 지점을 골라내는 일, 지점들을 한 사건으로 잇는 일, 며칠에 걸친 추적이다.

## 화면 구성 (PC 웹)

| 화면 | 내용 | 첨부 그림 후보 |
|---|---|---|
| 내 퇴직금(첫 화면) | 사건의 현재 단계, 다음에 할 일 하나, 남은 기한 | |
| 받을 계좌 | 지점 1·4. 선택지 카드 둘과 "나중에 꺼낼 일이 있나요" 되묻기 | 1 |
| 회사에 낼 것 | 계좌 확인 서류, 회사 담당자에게 보낼 내용, 14일 지급 기한 안내 | |
| 일정 | 서류 제출 → 지급 기한 → 입금 확인 → (현금 수령이면 60일) | 3 |
| 꺼내기 전 | 지점 2·5. 필요한 금액 입력, 세 경우 비교표(그대로 두기 / 다른 돈으로 메우기 / 해지하기) | 2 |
| 기록 | 누가(손님·비서) 언제 무엇을 했는지, 손님이 본 비교표 | |
| 오른쪽 비서 칸 | 상황 듣기, 되묻기, 선택지 카드, 사람 상담 연결 | 그림마다 함께 보임 |

비교표의 줄은 넷이다: 지금 떼는 세금, 필요한 금액과 깨야 하는 금액의 차이, 본인 납입분이 섞여 있으면 붙는 16.5%, 남겨 둘 때 55세 예상 금액의 범위. 마지막 줄은 "지금 쓰는 값과 맞바꾼 것"이라는 설명을 함께 둔다. "IRP에 두면 세금상 이득"이라는 줄은 넣지 않는다.

## 손님이 거치는 길

1. 손님이 "퇴사한다"고 말하거나 "내 퇴직금"을 연다. 비서가 퇴사일, 예상 퇴직금, 기존 IRP 유무, 꺼낼 계획을 묻는다.
2. 받을 계좌 선택지를 본다. 고르면 개설이 필요한 경우 휴대폰으로 넘기는 연결을 받는다(본인 확인은 손님이 직접).
3. 회사에 낼 계좌 확인 서류를 받아 직접 낸다.
4. 일정 화면에서 지급 기한과 입금을 기다린다. 입금되면 알림이 온다.
5. 돈이 필요해지면 "꺼내기 전"에서 필요한 금액을 넣고 세 경우를 본다.
6. 그대로 두기, 다른 돈으로 메우기, 해지 가운데 고른다. 해지에만 붙는 단계는 본인 인증 하나뿐이다.
7. 판단이 어려우면 본 내용을 요약해 연금 상담 직원에게 넘긴다.

## 왜 웹인가 (재료, 근거 미확인)

- 퇴사 서류(계좌 사본, 퇴직소득 원천징수영수증 PDF)는 PC에서 주고받는 일이 많다(조사자 추측).
- 선택지 비교표와 일정은 넓은 화면에서 한눈에 보인다(조사자 추측).
- 약점: 하나증권 퇴직연금 페이지가 "모바일앱에서 간편하게 IRP 계좌 개설"이라고 안내한다. 개설 단계는 휴대폰으로 넘겨야 할 수 있다.

## 정할 값 (시안에 넣을 값은 임시다)

| 값 | 기본값 | 정할 때 볼 것 |
|---|---|---|
| 입금 확인 알림 | 지급 기한(퇴직 후 14일) 다음 날까지 입금이 없으면 알림 | 회사와 지급일을 미룬 경우 |
| 60일 알림 | 남은 14일, 3일 | 근속이 짧으면 돌려받을 세금이 수만 원이라 알림이 과할 수 있다 |
| 55세 예상 금액의 수익률 가정 | 연 3%와 5% 두 줄 | 물가·수수료 미반영이라는 설명을 붙일지 |
| 사람 상담으로 넘기는 조건 | 손님 요청, 법정 인출 사유 해당 여부가 애매할 때, 비서가 뜻을 못 가를 때 | 연금자산관리센터 운영 시간(평일 8~17시) |
| 타사 연금 조회 | 손님이 켜면 조회 | 조회 결과를 개설 제안에 쓰려면 별도 동의가 필요하다 |

## 회사 쪽에서 필요한 것

| 필요한 것 | 왜 | 지금 있는지 |
|---|---|---|
| IRP 계좌의 재원 구분(퇴직금, 본인 납입, 운용수익) | 섞임과 16.5%를 보여 주려고 | 금융사가 보관하는 항목이다(소득세법 서식 기준). 손님 화면에 보이는지는 확인하지 못함 |
| 전액 해지 시 원천징수 예정액 | 영수증을 읽지 않고 확정 금액을 보여 주려고 | 금융사가 계좌별로 보관한다(같은 서식). 조회 기능 유무는 확인하지 못함 |
| 퇴직급여 입금·과세이연 등록 신호 | 입금 확인 알림 | 있을 것이다(추론) |
| 계좌 확인 서류의 웹 발급 | "회사에 낼 것" 화면 | 확인하지 못함. 고객센터 질문 3번 |
| 웹에서 휴대폰 개설로 넘기는 연결 | 개설 단계 | 확인하지 못함 |
| 마이데이터의 타사 IRP·DC 조회 | 타사 계좌 조합 확인 | 2021년 본허가 보도뿐. 현재 범위 미확인 |

## 잘 되고 있는지 재는 값 (제안)

| 재는 값 | 뜻 |
|---|---|
| 사건을 연 손님 가운데 받을 계좌를 입금 전에 정한 비율 | 받기 전 지점이 쓰이는가 |
| 해지한 손님 가운데 해지 전에 비교표를 본 비율 | 깨기 전 지점이 닿는가 |
| 해지 뒤 "받은 금액이 예상과 다르다"는 문의 건수 | 놀람이 줄었는가 |
| 퇴직금이 하나증권 IRP로 들어온 건수와 금액 | 회사 쪽 효과 |
| 이용 손님의 12개월 뒤 다른 계좌 개설률 | 주거래 가설 검증(지금은 근거 없는 가설) |

**유지율은 목표로 삼지 않는다.** 유지율을 성과로 잡으면 해지를 어렵게 만들 유인이 생긴다. 해지를 부당하게 제한하는 약관은 감독규정의 심사 항목이다(퇴직연금감독규정 제20조 제6호).

## 수익 설명 재료 (금액이 아니라 구조로)

- 직접 수익은 0에 가깝다고 먼저 밝힌다. 비대면 IRP는 수수료가 무료다(하나증권 FAQ 467, 응모자 재열람 필요).
- 퇴직연금은 경품이 3만 원으로 묶인 시장이다(퇴직연금감독규정 제16조 제2항). 같은 규정이 세무·운용 교육과 상담 비용은 특별이익에서 뺀다. 서비스가 남은 유치 수단이라는 논리다(조사자 추론).
- 하나증권 IRP는 6,429억 원에서 8,926억 원으로 38.8% 늘었다(2025년 말 → 2026년 3분기 말, 기사 경유). 회사가 미는 사업이라는 근거이지 이 서비스의 수익은 아니다.
- 주거래 선점은 가설로 표시하고, 위 "재는 값"의 마지막 줄을 검증 방법으로 붙인다.
- 쓰면 안 되는 서술: 0.311%를 회사 수익률로, 1억 원당 40만 원 유치비, 발행어음 조달 효과, 잠금효과.

## 받을 계좌에 관한 확인된 사실 (2026-11-26 추가)

- 하나증권은 퇴직금용과 세액공제용 IRP를 한 계좌로 합쳐 두고, 사업자마다 한 사람에 한 계좌다(하나증권 FAQ 470·469, 원문 확인). 그래서 하나증권 안에서 "따로 받기"는 그리지 않는다.
- 시안의 손님은 세액공제용 IRP가 다른 금융사에 있는 경우다. 이때 "따로 받기"는 하나증권에 새 IRP를 여는 것이고, 하나증권으로 받을 사실에 근거한 이유가 된다.
- 세액공제용 IRP가 하나증권에 있는 손님에게 정직한 답은 "다른 금융사에 새로 여는 것"이다. 서비스는 이 경우도 그대로 보여 준다.
- 금감원 「퇴직연금 가이드북」(2026-11-03 발간, 원문 확인)이 "퇴직급여는 개인자금이 납입되지 않은 퇴직IRP 계좌로 구분하여 수령하는 것을 권장"한다. 2021년과 2022년 금융꿀팁도 같은 내용이다. 근거 전체는 `docs/08_evidence_demand_and_difference.md`.

## 이 정의가 무너지는 조건

- 하나증권 웹이나 앱에서 수령 계좌 안내, 해지 전 내 금액 세액, 전액 해지 안내가 이미 한 흐름으로 나온다.
- 하나증권 사무담당자 매뉴얼의 800번/820번 구분이 지금도 맞아서 하나증권 안에서 퇴직금 계좌만 따로 해지할 수 있다(FAQ 470과 어긋난다. 고객센터 확인 필요. 맞다면 지점 1을 다시 쓴다).
- 후기와 설문에서 "결정에서 막혔다"가 나오지 않는다.
